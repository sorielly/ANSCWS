What Makes It Tick

Every part of the app was written from scratch — no component libraries, no CSS frameworks. Just React, hooks, and a clear architecture.

Context + State Architecture

Global CMS mode and font size are managed through a React Context, giving every component access without prop-drilling. Page-level data (events, programs, trails) lives in root state and flows down cleanly.

createContext useContext useState useCallback

Async Data Fetching

The weather widget uses useEffect with a mounted-flag cleanup pattern to prevent state updates on unmounted components. It polls the Open-Meteo API every 15 minutes via setInterval with full error handling and a loading state.

useEffect Async/Await Abort cleanup

Touch + Mouse Event Handling

The trail map supports both mouse drag (desktop) and single-finger touch drag (mobile) for panning when zoomed in, using a unified drag-state pattern with useRef and transform-based positioning.

useRef onTouchStart/Move CSS Transform

Zero-Dependency Icon System

All icons are hand-authored inline SVGs inside a single Icon component. No icon font, no library. Each icon accepts a size prop and inherits currentColor from its parent for seamless theming.

SVG currentColor Tree-shakeable

Inline CMS Architecture

EditableText renders either plain text or an editable <input> / <textarea> depending on CMS mode — all driven by a single boolean in Context. Every change is logged to an audit trail with timestamp and action description.

Conditional render Audit log useCallback

Responsive Without a Framework

All layouts use CSS Grid with auto-fit / minmax() so they reflow naturally at any viewport width. Breakpoint overrides are scoped to a single injected <style> tag inside the Navigation component.

CSS Grid auto-fit clamp()
